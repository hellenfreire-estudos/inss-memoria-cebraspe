🧠 Como a NASA aprende

O sistema guarda seu desempenho no aparelho e usa erros e acertos para definir a prioridade das próximas questões.

A NASA combina banco autoral com o índice de itens oficiais CEBRASPE disponíveis. Questões oficiais com texto integral só entram quando o respectivo caderno oficial é fornecido como fonte de importação. O motor adapta a frequência: erro aumenta prioridade; acerto consistente aumenta intervalo.

⚙️ Configuração do Push

Sem OneSignal. O NASA usa Web Push padrão. Você só precisa colar a URL do pequeno servidor de Push e a chave pública VAPID.

Como funciona: o NASA decide o que revisar; o Web Push apenas entrega a notificação na tela do iPhone. Para receber avisos com o app fechado, o PWA precisa estar instalado na Tela de Início e inscrito no Push.

🏛️ Banco CEBRASPE — referência oficial

A NASA separa questões autorais das questões oficiais. O índice oficial mantém prova, item, gabarito quando disponível e fonte oficial. O texto integral das questões da banca deve ser consultado no documento do Cebraspe.

A base autoral é estruturada pelo edital de 2022; a prova oficial de 2026 fica separada para não misturar automaticamente conteúdos de períodos distintos.
